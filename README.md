# Text to Image Generator

This project is a simple Generative AI application that generates images from text descriptions.  
Users enter a text prompt in a web interface, and the system creates an image based on that input using a pre-trained Stable Diffusion model.

The application is built using Python and Streamlit and focuses on demonstrating the practical use of Generative AI without training any model from scratch.

---

## Features
- Generate images from natural language text prompts
- Simple and user-friendly web interface
- Uses a pre-trained diffusion model for image generation
- No model training required

---

## Technologies Used
- Python
- Streamlit
- Stable Diffusion (pre-trained model)
- Diffusers library

---

## How It Works
1. The user enters a text description in the web interface.
2. The application sends the prompt to a pre-trained Stable Diffusion model.
3. The model generates an image based on the text input.
4. The generated image is displayed on the screen.
